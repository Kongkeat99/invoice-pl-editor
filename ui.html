    What it does
    Invoice: checks page 1 → removes “Shipment” from the header → replaces the manufacturer address → checks the last page → adds the “For and on behalf of” block.
    Packing List: checks page 1 → replaces the manufacturer address.
    Files are processed on this computer only. The original files are never changed; results are saved in the output folder with the same file name.
    The “digitally signed” line is plain text, not a cryptographic signature. Use it only where you are authorized to.
